# Bind — Canonical Release V2

This repository contains the canonical software and experimental artifacts for the Bind V2 release accompanying:

**Bind: Causally Certified Computational Matter**

The release centers on the flagship computational object:

`ECR2MF_g0_field_s1002`

The object was discovered through the Embodied Cognitive Runtime (ECR), causally tested, promoted into the Machine Factory archive, reused by a later generation, and carried through the software-to-hardware representation used in the paper.

## The computational object

The central idea in Bind is that a discovered computational organization can become a persistent object rather than remaining a temporary result of a search.

A certified object carries its:

- identity
- certificate
- lineage
- executable representation
- integrity information
- validation evidence

This allows the same object to move through discovery, validation, reuse, and hardware realization while remaining identifiable throughout the process.

RECONFIGURABLE COGNITIVE FABRIC
The RCF is the hardware direction developed from the canonical release. Rather than requiring a completely new host for every computational organization, the host remains fixed while certified organizations can be loaded, unloaded, restored, and gated.

The V2 artifacts include the generic RCF implementation and its associated hardware-generation path. The current release demonstrates this path in software and RTL, including synthesis and place-and-route. Physical FPGA hot-loading is a subsequent hardware validation step.

WHAT THIS RELEASE DOES NOT CLAIM
This release is intentionally limited to the evidence demonstrated in the paper. It does not claim:

artificial general intelligence
consciousness
open-ended evolution
a successful multi-hop causal certificate chain
universal equivalence for arbitrary future organizations
physical robot developmental learning
fabricated cognitive ASIC hardware
The physical board and physical robot loop are future engineering work.


REPRODUCIBILITY
The canonical release is intended to provide a stable reference point for reproducing and inspecting the flagship result without requiring the full historical development tree.

The release artifacts include the components required to inspect:

the certified matter object
its lineage
causal tests
software execution
IR equivalence
hardware generation
RCF behavior
gate-off and restoration behavior
For deterministic tests, the release uses fixed inputs, seeds, stimuli, and tolerances defined by the corresponding experimental protocols.
